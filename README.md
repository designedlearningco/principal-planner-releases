# Principal Planner — downloads

This repository holds the installers for **Principal Planner**, an offline
planning app for Queensland state special school principals, made by
Designed Learning Co.

There is no source code here: only the files you install.

**The simplest place to download is the website, which also has install steps:**
**https://designedlearningco.au/principal-planner-download.html**

## Which file do I need?

Download from the [latest release](../../releases/latest):

| Your computer | File |
| --- | --- |
| A Mac from late 2020 or newer (Apple M1, M2, M3, M4 …) | `PrincipalPlanner-Mac-Apple-Silicon.dmg` |
| An older Mac with an Intel processor | `PrincipalPlanner-Mac-Intel.dmg` |
| Windows 10 or 11, 64-bit | `PrincipalPlanner-Windows-Setup.exe` |

Not sure which Mac you have? Apple menu → **About This Mac**. If it says
*Apple M1* (or M2, M3, M4) under Chip, use Apple Silicon. Mac versions need
macOS 13 Ventura or newer.

You do not need a licence key to install. The download is the free version;
a key, entered later in **Settings → Licence**, unlocks the rest without
changing anything you have entered.

## Installing

- **Mac:** open the `.dmg`, drag Principal Planner onto Applications, open it.
  It is signed and notarised by Apple.
- **Windows:** run the setup file. If a blue *"Windows protected your PC"* box
  appears, click **More info**, then **Run anyway**. It installs for your
  account only, so no administrator password is needed.

Nothing needs the internet: an installer copied onto a USB stick works the
same way on a school computer.

## Your information

Principal Planner has no account and no server. Everything you enter stays on
your own computer. It only goes online when you press **Sync now**, to
download the Department's public school calendar.

## Independent

Principal Planner is not made, endorsed or checked by the Queensland
Department of Education. Its planning suggestions are its own; anything that
depends on departmental policy says *Verify current departmental
requirements*.
